Игра по локальной сети

Хозяин запускает сервер на своём компьютере. Игроки в той же сети подключаются по адресу или QR-коду из панели.

Открыть локальную панель

Первый запуск на компьютере хозяина
  1. Установите Node.js 22.12 или новее и скачайте ветку LAN.
  2. Распакуйте архив и откройте терминал в папке проекта. 
    npm ci
npm run lan
  3. Откройте панель, выберите сетевой интерфейс и нажмите «Запустить сервер». Игра соберётся автоматически.
