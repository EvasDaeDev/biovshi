# Исходные материалы

Эта папка расположена вне `public/` и не копируется в сборку Vite.

- `textures/` — PSD, референсы, разметка атласов и неиспользуемые изображения.
- `sounds/` — исходные записи и неиспользуемые звуки.
- `texture-inputs/textures/` — оригиналы для `npm run textures`; готовые WebP создаются в `public/assets/textures/`.

Файлы игры перечислены в `src/assets/manifest.js`. Для подключения материала
сначала подготовьте рабочую версию в `public/assets/` и добавьте её в манифест.
Исходники сохраняйте здесь.
