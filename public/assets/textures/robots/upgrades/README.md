# Атласы для модификаций протезов

В игре подключены 23 отдельных PNG-атласа. Они используются в бою,
предпросмотре Убежища и карточках деталей. Для замены рисунка сохраните
имя PNG, сетку и координаты креплений. Общий рабочий файл — `ar_mod_src.psd`.

## Как устроен атлас

- Размер каждого PNG: **256 × 256 px**, сетка **4 × 4** по **64 × 64 px**. Прозрачность сохранить.
- В сборку включаются PNG из манифеста. Рабочий PSD хранится отдельно от игрового артефакта. После правки экспортируйте нужный PNG под его игровым именем.
- При изменении конкретной части тела сохраняй общую позицию сегмента внутри его ячейки, масштаб и ось сустава **y = 32 px**. Не сдвигай ячейки и не изменяй число пикселей между точками крепления.
- Рисуем **полную замену текстуры сегмента**, не навесную наклейку. Нужные части можно полностью перерисовать; остальные ячейки по возможности оставить исходными.
- Стилистика БиоВшей: грязный ретро-медицинский/индустриальный биопанк, потёртый металл, приглушённые цвета, без яркого неона и анимешных контуров.

## Как атласы подключаются к игре

- **Хирургия** привязана к *одному конкретному сегменту*, поэтому из атласа операции должна выбираться только ячейка этого сегмента. Для руки и ноги подготовлены варианты обеих сторон и обоих участков.
- **Сегментные модификации** заменяют одну совместимую ячейку атласа. Установленная деталь определяет внешний вид своего сегмента. Предпросмотр операции может временно показать хирургический атлас в той же ячейке.
- **Старые целые модули** используют детерминированное распределение подходящих текстур по ячейкам. У проведённой операции есть свой атлас на её сегменте. Игровые бонусы складываются по правилам оснащения.
- **Синергии** трёх семейств не требуют собственных атласов: их внешний вид должен составляться из установленных модификаций.
- **Сейчас подключено:** `src/tower/upgrade-appearance.js` выбирает PNG для сегмента, `src/render/robot-skin.js` рисует им тело в бою и сохраняет путь при отрыве, а `src/tower/upgrade-preview.js` показывает того же пациента **лёжа горизонтально, головой справа** в Убежище. В `src/assets/manifest.js` перечислены все 23 PNG, чтобы они работали также в автономном HTML.
- Если новый файл отсутствует или повреждён, игра возвращает **только проблемный сегмент** к прежней текстуре. Числовые улучшения при этом сохраняются.
- Базовый атлас андроида `ar_01.png` хранится отдельно от игровых PNG улучшений.

## Контроль готовности

1. В каждом PNG 256 × 256, 4 × 4 сетка, RGBA/прозрачность сохранены.
2. Центры шарниров и длины соответствуют исходнику; конечности не выходят за границы своей ячейки.
3. Изменение видно в игровом масштабе сверху, а не только при увеличении.
4. Экспортированный PNG совпадает с утверждённой правкой исходника.

Оригинал: `public/assets/textures/robots/ar_01.png` и `ar_01.psd`.
