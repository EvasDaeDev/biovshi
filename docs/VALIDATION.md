# Проверка изменений и публикации

На ветке `test/combat-hit-sync` с Node.js 22.12 или новее:

```sh
npm ci
npm test -- --test-concurrency=2 --test-timeout=120000
npm run build -- --mode test
npm run preview
```

В каталоге результата ожидаются тестовый `index.html`, `build-info.json`,
`Editors/location-editor.html` и `locations/active.json` с файлами активных
локаций. Для отдельной проверки основной сборки выполните `npm run build`.
Для проверки автономного запуска выполните `npm run standalone` после обычной
сборки и откройте `dist/biovshi.html` с диска.

### GitHub Pages

Ветка `test/combat-hit-sync` запускает проверки боевой регрессии и запрос
на публикацию. Основной workflow проверяет и собирает `main` и тестовый
коммит, после чего объединяет их в одном артефакте. Из исходников тестовой
ветки команда `node scripts/check-pages-preview.mjs <каталог-сайта>`
проверяет уже объединённую структуру с подпапкой `test/`. Проверка охватывает
метаданные тестового канала, ссылки на файлы страницы игры и редактора,
SHA закреплённого Telegram SDK и область PWA-манифеста. Упаковщик Vite
отдельно проверяет содержимое сборки и исключает рабочие исходники.

После публикации проверьте `sourceCommit` в [метаданных теста](https://evasdaedev.github.io/biovshi/test/build-info.json)
и откройте [редактор](https://evasdaedev.github.io/biovshi/test/Editors/location-editor.html).
Полные требования описаны в [правилах ресурсов](ASSET_BUILD_RULES.md).

### Ручная проверка

Пройдите [чек-лист игры и редактора](TOWER_PART_2_TESTER_CHECKLIST.md).
Автотесты DOM и физики проверяют состояние, ввод и расчёты. Внешний вид,
графику WebGL, звук и работу конкретного Telegram WebView проверяют на
целевом устройстве. [Сценарии Telegram](TELEGRAM.md#проверки).

## История переноса

Дата: 7 ноября 2026.

Исходник: `biovshi-gladiators-totalizator (10).html`.

- `npm test`: 9 тестов, все пройдены. Проверяются выплаты и сохранность фишек,
  округление, джекпот, возврат ставок, защита от повторного расчёта, неуязвимая
  грудь, потеря головы, замедление поворота, отрыв дочернего сегмента,
  остановка без конечностей, сброс, финал боя и игровые события.
- `npm run build`: обычная сборка Vite успешно создана.
- `npm run standalone`: одиночный HTML успешно создан.
- Все JS-модули проверены `node --check`.
- Три сравнительных прогона исходной и модульной версии при одинаковой
  случайной последовательности: seed 17, 12345, 987654; по 7200 шагов
  (120 секунд симуляции). Отрисовка вызывалась через шаг, камера — каждый шаг.
  Каждые 300 шагов сравнивались координаты, углы, HP, позы, состояния роботов,
  бой, таймер, камера и тотализатор. Различий не обнаружено.
- Итоговая SVG-разметка арены совпала целиком во всех трёх прогонах.
  Попаданий соответственно: 90, 74, 74. Состояния после сброса также совпали.
- Готовый одиночный HTML проверен с адресом file:// и недоступным localStorage:
  создание сессии, старт, пауза, продолжение, сброс. Внешних скриптов и CSS нет.

Сравнение и проверка интерфейса выполнены в JSDOM. Это проверяет данные,
DOM/SVG и обработчики, но не фактическую растеризацию, раскладку CSS или
воспроизведение аудио в браузере. Chromium в этой среде запустить не удалось;
проверка скриншотов и реального звука не выполнена. Новые текстуры и аудиофайлы
в поставку не добавлялись; точки подключения и ограничение числа звуков готовы.

Временные инструменты сравнения, исходный монолит, node_modules и браузерные
зависимости в архив не включены. Воспроизводимые тесты находятся в tests/.
