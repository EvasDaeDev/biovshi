# Проверка переноса

Дата: 7 ноября 2026.

Исходник: `biovshi-gladiators-totalizator (10).html`.

- `npm test`: 9 тестов, все пройдены. Проверяются выплаты и сохранность фишек,
  округление, джекпот, возврат ставок, защита от повторного расчёта, неуязвимая
  грудь, потеря головы, замедление поворота, отрыв дочернего сегмента,
  остановка без конечностей, сброс, финал боя и игровые события.
- `npm run build`: обычная сборка Vite успешно создана.
- `npm run standalone`: одиночный HTML успешно создан.
- Все JS-модули проверены `node --check`.
- Три сравнительных прогона исходной и модульной версии при одинаковой
  случайной последовательности: seed 17, 12345, 987654; по 7200 шагов
  (120 секунд симуляции). Отрисовка вызывалась через шаг, камера — каждый шаг.
  Каждые 300 шагов сравнивались координаты, углы, HP, позы, состояния роботов,
  бой, таймер, камера и тотализатор. Различий не обнаружено.
- Итоговая SVG-разметка арены совпала целиком во всех трёх прогонах.
  Попаданий соответственно: 90, 74, 74. Состояния после сброса также совпали.
- Готовый одиночный HTML проверен с адресом file:// и недоступным localStorage:
  создание сессии, старт, пауза, продолжение, сброс. Внешних скриптов и CSS нет.

Сравнение и проверка интерфейса выполнены в JSDOM. Это проверяет данные,
DOM/SVG и обработчики, но не фактическую растеризацию, раскладку CSS или
воспроизведение аудио в браузере. Chromium в этой среде запустить не удалось;
проверка скриншотов и реального звука не выполнена. Новые текстуры и аудиофайлы
в поставку не добавлялись; точки подключения и ограничение числа звуков готовы.

Временные инструменты сравнения, исходный монолит, node_modules и браузерные
зависимости в архив не включены. Воспроизводимые тесты находятся в tests/.
