# Тестовые бои Башни — 17 ноября 2026

**Ветка:** `experiment/tower-bosses` (без публикации и переноса в `main`).  
**Метод:** автоматические headless-бои внутри настоящего игрового цикла `step(1/60)` (JS DOM). Используются текущие столкновения, враги, повреждения, атаки и ИИ, **не** математическая имитация исходов. Игроком управляет простой программный автопилот; результаты **не** являются оценкой побед человека.

Исходный симулятор: `scripts/experiment-tower-fights.mjs`. Запуск в GitHub Actions `.github/workflows/tower-experiment.yml`.

**Наблюдение:** длительные бои при осторожном движении игрока особенно часты в «Кольце», «Шлюзе» и «Колоннаде» с максимальным составом. ## Приоритеты следующих проверок

1. **Глубина динамических перекрытий:** собирать максимальное проникновение тел, а не только количество кадров с наложением.
2. **Рывок `long_legs`:** диагностировать, почему не строится `chargePlan`, на нескольких стартовых позициях. Подтвердить, что это не следствие ограничений конкретной «Колоннады».
3. **Длительные схватки:** разнести причины по категориям: игрок держит дистанцию, низкая мобильность из-за ампутаций, отсутствие доступных атак, препятствия.
4. **Ручной баланс:** протестировать живое управление в Telegram WebView — победы автопилота нельзя считать прогнозом сложности для игрока.
5. **Повторяемость и оптимизация:** продлить отдельные прогоны, измерить время CPU на разных количествах участников, проверить FPS на устройствах.

## Воспроизведение

Команды при наличии полной копии репозитория и зависимостей:

```bash
npm ci
npm test
npm run build
node scripts/experiment-tower-fights.mjs --seeds=1 --limit=35 --policy=approach --out=artifacts/tower-approach.json
node scripts/experiment-tower-fights.mjs --seeds=3 --limit=75 --policy=orbit --out=artifacts/tower-orbit.json
```

GitHub Actions в прогоне B подтвердил прохождение `npm test`, `npm run build` и этапа симуляций; подробный файл `tower-fights.json` доступен среди artifacts соответствующего запуска.

**Важное ограничение:** бои создаются с заранее определёнными составами для покрытия геометрии и анатомий; это не замер вероятностей генератора этажей. Для боёв использован простой автопилот, а не человек.
