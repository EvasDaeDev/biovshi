# Эксперимент: индивидуальные диапазоны тактических решений

Состояние: **исследовательская ветка, не переносить в main без улучшения показателей**.

## Изменения

- Решения о дистанции фланга, сближении и защите головы используют один раз выбранные на раунд диапазоны.
- Лево/право задаётся случайной тактической стороной, фиксированной на 3,5–8 секунд и обновляемой при смене противника, а не чётностью ID.
- У каждого пациента собственный таймер последнего попадания: общая активная схватка больше не обновляет его «таймер результативности».
- Отсутствие сближения на интервале 4,5–7,5 с вызывает короткий поперечный манёвр (разрыв кругового преследования), без телепортации.
- Смерть/здоровье/статы/углы зрения/слух/таймер потери сознания не менялись.
