# Редакторы локаций и скелета

## Редактор локаций

Откройте [редактор в тестовой сборке](https://evasdaedev.github.io/biovshi/test/Editors/location-editor.html).
Для разработки запустите `npm run dev -- --mode test` и добавьте
`/Editors/location-editor.html` к локальному адресу, который покажет Vite.

### Рисование и преобразования

| Инструмент | Действие |
| --- | --- |
| «Стена» | Протяните от начала до конца. Толщина задаётся в сантиметрах. |
| «Прямоугольник» | Протяните между противоположными углами препятствия. |
| «Круг» | Протяните от центра до края. Рядом с координатами отображается радиус. |
| «Контур» | Отметьте вершины, затем нажмите первую вершину, Enter или «Замкнуть». Допускаются вогнутые формы. Самопересечения отклоняются. |
| «Выбор» | Щёлкните объект или стартовую точку. Объект можно перетаскивать, а Delete удаляет выделенное. |

У выбранного объекта стрелки пивота перемещают его по экранным осям X и Y,
центр перемещает свободно, квадрат меняет масштаб, кольцо вращает с шагом 5°.
Кнопки ↶ и ↷ и клавиши Q/E также вращают на 5°. В режиме «Сместить пивот»
перетащите золотую точку. «Пивот в центр» возвращает геометрический центр.
Смещённый пивот сохраняется в JSON вместе с объектом.

Симметрия X отражает координату X относительно середины ширины, симметрия Y —
координату Y относительно середины высоты. Переключатели независимы и действуют
при создании, перемещении, повороте, масштабировании и удалении объектов.

### Проверка размеров и стартов

- Ширина и высота задаются отдельно от 300 до 1600 см. Для нового плана можно настроить срез углов. Импортированный внешний контур масштабируется вместе с ареной.
- «Проверить план» измеряет кратчайшие зазоры между отдельными объектами и до периметра. Стыкующиеся части считаются замкнутым участком. Порог по умолчанию — 120 см. Узкие зазоры подсвечиваются. Проверка зазоров оценивает эти расстояния, а проходимость нужным телосложением проверяется в игре.
- В «Стартах Башни» поставьте одну точку игрока и до девяти точек противников. Противники получают их в порядке добавления. Остальные места игра подбирает автоматически. Подбор безопасной позиции учитывает всю анатомию и может сместить старт крупного бойца.
- Точки старта можно перетаскивать и удалять в режиме «Выбор». Зелёные точки после проверки плана показывают четыре старта тотализатора. Кнопка «Сбросить старты и патруль» возвращает автоматическую расстановку.
- «Болванка пациента» показывает габариты обычного пациента в нейтральной стойке в масштабе 1:1. Разместите её в проходе, поверните клавишами Q/E или нажмите «Убрать». Её данные остаются в редакторе.

### Экспорт и подключение к игре

1. Нажмите «Экспорт JSON». Имя файла должно совпадать с полем `id`.
2. Положите файл в [`public/locations/`](../public/locations/) и добавьте `id` без расширения в массив `active` файла [`active.json`](../public/locations/active.json). Чтобы отключить арену, уберите из массива её `id`.
3. Обновите локальную страницу игры. Для публичной игры обновите файлы `locations/` рядом с её `index.html` через публикацию сборки.

Веб-игра читает каталог и активные JSON при каждом открытии страницы.
Недоступные и некорректные файлы пропускаются с сообщением в консоли. Если
каталог загружен, но подходящих файлов нет, выбирается резервная Операционная.
При недоступном или некорректном каталоге используется встроенный набор.
Автономный HTML по `file://` также использует встроенные арены.
Изменение каталога действует после перезагрузки. В сохранённом плане Башни
игра подбирает совместимую замену удалённой арене с учётом числа бойцов.

### Поля JSON

Координаты — локальные сантиметры. X растёт вправо, Y — вниз.

| Поле | Назначение |
| --- | --- |
| `version`, `id`, `name` | Версия формата 1, имя файла без расширения и название в игре. |
| `size` или `width` и `height` | Сторона квадратной арены или размеры прямоугольной. |
| `cornerCut` или `boundary` | Срез углов или список вершин выпуклого внешнего контура. |
| `capacity` | Вместимость в Башне вместе с игроком, от 2 до 10. Для тотализатора всегда подбираются четыре старта. |
| `objects` | До 64 стен и препятствий с `kind` и замкнутым контуром `points`. Повтор первой вершины в конце необязателен. Круг сохраняется вершинами, вогнутый контур может содержать до 32 вершин. |
| `objects[].pivot` | Необязательная точка преобразований объекта в координатах арены. |
| `minPassage` | Порог подсветки узких зазоров в сантиметрах. |
| `spawns`, `patrol` | Необязательные фиксированные старты тотализатора и точки патруля. |
| `towerSpawns.player`, `towerSpawns.opponents` | Необязательные ручные старты игрока и упорядоченный массив стартов противников в Башне. |

## Редактор скелета пациента

Сохраните файл [`Editors/biovshi-patient-rig.html`](../Editors/biovshi-patient-rig.html)
и откройте его в браузере. Страница самодостаточна и работает с диска.
На сантиметровой сетке можно выбрать пациента A–D, включить текстуры и кости,
перетаскивать точки или вводить координаты вручную. Начало координат — исходная
точка груди. Ось X направлена вправо, ось Y — вниз.

- «Фиксировать длины сегментов» позволяет менять позу с сохранением текущих длин. С выключенным переключателем можно редактировать длины.
- Симметрия отражает парные точки относительно линии `Y = 0`. При одновременной фиксации длин и симметрии крепления плеч и бёдер закреплены.
- «Экспорт JSON» сохраняет координаты всех четырёх пациентов в `biovshi-patient-rig.json`. Этот же файл можно открыть через «Импорт JSON».

### Как передать координаты в игру

Передайте экспортированный JSON и укажите, применяется ли поза ко всем
пациентам A–D или файл показывает одну эталонную позу. JSON скелета служит
источником координат при правке игры. Базовые крепления, длины конечностей
и вынос головы задаются в [`src/robot/body.js`](../src/robot/body.js).
Редактор выдаёт сантиметры. При переносе в локальные единицы скелета
используется `CONFIG.robot.scale` из [`src/config.js`](../src/config.js).
Проверка нейтральной стойки и болванка редактора локаций используют общую
[`src/robot/neutral-pose.js`](../src/robot/neutral-pose.js).
