# Башня: сегментные модификации

Статус: утверждённые правила (19.11.2026). Реализация по этапам.

## Награда за босса
- Победа автоматически выдаёт одну либо две части модификаций с вероятностями 50/50.
- Тип модификации и совместимая ячейка атласа выбираются независимо для каждой награды.
- Оба предмета могут принадлежать разным комплектам или полностью совпадать.
- Отказ от старого выбора одного целого комплекта.
- Редкость каждой части определяется действующим циклом Башни.

## Инвентарь и экипировка
- Одна часть: индивидуальный ID, тип модификации, конкретный сегмент тела, ранг редкости.
- Склад сохраняется между смертями; установленная сборка погибшего пациента теряется без ДМС.
- Одинаковые тип + сегмент + редкость группируются в стопки; счётчик экземпляров — в нижнем правом углу ячейки.
- Разная редкость — отдельные стопки.
- Ограничение — один установленный модуль на анатомический сегмент. Старый лимит шести модификаций отменяется.
- Каждая установленная часть даёт полный текущий бонус типа. Бонусы частей суммируются.
- Замена: старая часть возвращается на склад бесплатно, новая ставится за 75 монет. Снятие бесплатно.
- Рядом с кнопкой установки — активная для выбранного складского предмета кнопка продажи.

## Экономика
- Установка: 75 монет, без роста цены.
- Продажа одного экземпляра: `round(50 * (1 + 0.12 * rarity))`.
- Цена при рангах 0–5: **50 / 56 / 62 / 68 / 74 / 80** монет.
- Продажа подтверждается игроком.

## Риск, смерть, ДМС
- Без ДМС после гибели остаются все **неустановленные** части на складе.
- Установленные части и проведённая хирургия теряются, не возвращаясь на склад.
- ДМС сохраняет защищённый в действующей системе страхования пациентский набор: сегменты, редкость, операции и геометрию.
- Неустановленный склад сохраняется независимо от ДМС.

## Графика
- Награда, инвентарь, Убежище и арена отображают одну и ту же ячейку атласа выбранной части.
- Установленный сегмент всегда отображает именно установленный предмет; графическая случайная подмена для таких частей запрещена.
- Цветная тонировка редкости индивидуальна.
- Новые анатомические сегменты после хирургии доступны для совместимой экипировки.

## Данные и миграция
- Обязательной миграции старых сохранений Башни не требуется.
- Посторонние сохранения игры не должны повреждаться.
- Необходимо проверить выдачу 1/2, независимый розыгрыш, дубликаты, редкости, цены, UI, бой, ДМС, смерть и целостность сохранений.
- Важно: полный бонус за *каждую* часть способен ускорить рост характеристик; баланс тестируется отдельно без самовольной корректировки утверждённых бонусов.
